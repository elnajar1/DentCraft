# Screenshot provenance

The six application screenshots were refreshed for **DentCraft 0.2.1** on 2026-11-04.
They show the real desktop application, without retouching its geometry or interface.

The preparation is generated by
`crates/dentcraft-design/examples/prepared_tooth_case.rs`; crown anatomy comes from
DentCraft's built-in parametric library. No patient scans, proprietary sample cases,
or external tooth libraries appear in these screenshots.

To reproduce the scene, build the application and the `prepared_tooth_case` example,
generate an STL and case outside `scratch/`, and open the case with:

```text
--margin 36@0,0,12 --tooth 36 --open expert-strip --size 1600x1000
--step anatomy --view occlusal --theme dark --screenshot screenshot-dark.png
```

Clear `DENTCRAFT_TOOTH_LIBRARY` for this public demonstration. The light screenshot
uses `--theme light`. The workflow panels use the `margin`, `axis`, `inner` and
`anatomy` steps; axis, inner and anatomy detail views use `--view facial`, and the
inner view adds `--section`.

The banner, logo and sponsor artwork are separate branding assets, not application screenshots.
