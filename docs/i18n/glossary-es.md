# Spanish glossary

Dental terms for the Spanish interface (neutral Latin American Spanish), so every screen uses the
same word for the same thing. Terms come from standard clinical and dental-laboratory vocabulary;
nothing is taken from the interface or documentation of proprietary CAD software.

Status: **reviewed** — chosen by the clinical reviewer; **proposed** — awaiting review.
Terms marked *used* appear in `crates/dentcraft/locales/es.ftl` today.

Address form: *usted* (e.g. "Haga clic en un diente…").
