# Security policy

Please do not report security problems in public issues.

Use GitHub's **Report a vulnerability** button on the
[Security tab](https://github.com/elnajar1/DentCraft/security) to send a private report. Include
the version or commit, the steps to reproduce and the impact you expect. You will get an answer
within seven days.

DentCraft reads mesh and case files from disk; malformed or hostile files that crash the program,
exhaust memory or write outside the chosen folder are in scope.
